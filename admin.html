1. Connect to GitHub

Only you can publish: saving needs your personal GitHub access key. It is kept only in this browser, never on the website. Visitors cannot change anything.

How to get the access key (one time, 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new (signed in as yourself).
  2. Token name: website editor. Expiration: 1 year (or what you prefer).
  3. Repository access: Only select repositories → choose .
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Click Generate token, copy it, and paste it below.

2. Photo

Choose a new portrait. It is resized automatically and published when you click Save & publish.

3. Edit the content

Open a section, change any text, add or remove items with the buttons, then click Save & publish at the top. The live site updates about one minute later.
